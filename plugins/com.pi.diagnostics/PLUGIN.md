# 运行诊断

右侧栏里的「运行诊断」面板：打开当前会话，就能看到这次 agent 运行的完整轨迹。

它回答的问题：

- 这一轮为什么慢——模型生成了多久，工具跑了多久，中间还等了多久。
- token 花在哪——每轮的输入 / 输出 / 缓存读取，以及缓存命中率。
- 哪里失败了——模型错误、工具错误、连续重试、被截断的输出。
- 工具执行前那几秒是工具慢，还是权限审批 / 排队。

数据来源是当前会话的 JSONL 日志（只读），不额外埋点、不上传。面板可见时每 3 秒自动刷新，右上角可以导出完整报告的 JSON。

## 开发

```bash
npm install
npm run build        # 后端打包到 dist/main.mjs
```

面板是静态页面（`ui/`），不需要构建。开发时用仓库的 dev 插件根目录启动：

```bash
pnpm dev:desktop:plugins
```
