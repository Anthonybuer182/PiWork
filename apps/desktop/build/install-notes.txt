PiWork 安装说明
================

1. 把 PiWork.app 拖到右边的「应用程序」文件夹。

2. 首次打开如果提示「无法验证开发者」：
   打开「系统设置 → 隐私与安全性」，在页面底部点「仍要打开」。

3. 如果双击后完全没有反应（macOS 26 会静默拦截，不再弹窗）：
   打开「终端」，执行下面这行命令，然后再打开即可：

   xattr -dr com.apple.quarantine "/Applications/PiWork.app"

原因：本版本没有 Apple Developer ID 签名和公证，macOS 会拦截从网上下载的应用。
上面这条命令只是告诉系统「这个应用我信任」，不会修改应用内容。
